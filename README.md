# Autumn Leaf Vision

A JavaFX application developed as part of a Data Structures and Algorithms assignment.

The application analyses an image to detect groups of autumn leaves and provides route planning between detected leaf clusters.

## Features

- Image processing and leaf detection
- Connected pixel grouping using a Union-Find data structure
- Route planning between detected leaf clusters
- JavaFX graphical user interface

## Technologies

- Java
- JavaFX
- Data Structures and Algorithms
- Union-Find
